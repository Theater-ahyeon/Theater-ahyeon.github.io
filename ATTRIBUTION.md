# Visual asset notes

This public edition uses original AI-assisted non-character environment concepts (`observatory.webp`, `gold-chamber.webp`) and original code-drawn diagrams for the displayed GitHub projects (`project-*.svg`). The diagrams are conceptual portfolio illustrations, not application screenshots. Dialogue diagrams are rendered directly from HTML and CSS.

No third-party character artwork, source-video frame, or private project screenshot is embedded. Visual-study reference links point to the original artists and official sources; their works remain with their respective authors and rights holders. Locally hosted fonts retain `assets/FONT-LICENSE.txt`.

Public project summaries and contribution links were checked against public repository metadata, README files and merged PR records on 2026-10-10. Non-fork status is not a claim of wholly original authorship; no unverified online-demo links are displayed.
